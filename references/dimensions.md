# 各维度的判定方法

第 3 步「归纳成画像」的展开。输出模板里每一栏怎么填，在这里。

## 立场

这一栏最难挖，因为人很少直接写"我反对什么"，但它是辨识度的主要来源，也是最难仿的部分。

### 立场藏在哪

按可靠性排序，逐处去找：

1. **二元对照里那个"错的版本"**。凡是"A vs B"这种对照，他立起来的那个反面就是他反对的东西——用对照法本身就是为了反对。
2. **寓言和类比的落点**。讲故事要花成本，一定是为了打某个靶子。问一句"他讲这个故事是为了反驳谁"，答案就是立场。
3. **自陈失败案例的归因**。人讲自己的失败时会给原因，那个原因就是他认定不该做的事。
4. **情绪温度异常处**。全篇平稳，某一段突然出现调侃、反问、加重语气、短句连发——温度异常的地方底下一定有立场。这条最容易漏，因为它不在内容里，在语气里。
5. **跨材料的重复**。同一个意思在不同文章、不同年份反复出现。他自己没意识到在重复，说明这是底层判断。
6. **他拒绝使用的东西**。反对造词的人自己不造词；反对买量的人举的成功案例里没有一个靠买量。这条要在"他没写什么"里找空缺。

### 每条立场必须成对

**只写"主张 X"不合格，必须同时给出"因此反对 Y"。**

没有反面的主张都是正确的废话——"主张给用户创造价值"，谁反对呢？配上"反对把发优惠券当成创造价值"，辨识度立刻出来。

而且挖不出反面本身是个信号：说明这条可能不是他的立场，只是他复述的行业共识，该删。

判定一条候选主张，问两个问题：**有没有人真的持相反意见？**（没有 → 是共识或三观，删掉）**它能不能改变下一篇怎么写？**（不能 → 留着没用）

### 取向层（可选）

单条价值观没有区分度，**组合有**。像政治图谱一样，一条轴只分两半，多条轴交叉才定位出人。不常见的组合辨识度最高。

只用预先定义的轴，不要自由发挥：

| 轴 | 两端 | 影响 |
|---|---|---|
| 决策观 | 集权 ↔ 共识 | 讲管理案例时的立场 |
| 对人的假设 | 人可教 ↔ 人难改 | 写"教你怎么做"还是"劝你别做" |
| 时间取向 | 长期 ↔ 短期 | 什么算成功案例 |
| 规则态度 | 守序 ↔ 变通 | 讲合规和灰度时的姿态 |
| 读者姿态 | 同辈 ↔ 过来人 ↔ 权威 | 人称、语气、要不要说教 |

**这一层本人自述最不可信**——比表达习惯还不可信，因为人讲价值观时会给体面版本。只能纯材料反推，每条至少两处交叉验证。允许留空，证据不足就标"证据不足"，硬填的取向会污染整个下游。

### 三道护栏（不装就会滑成人格评价）

**一、强度与内容分离。** 表达锋利是"怎么说"，立场极端是"说什么"，两者独立——完全可能锋利地持温和立场。措辞强度归肌理层，取向层只管内容。合并两者读出来的强度是虚的。

**二、禁用规范性形容词。** 过激、偏执、温和、理性、成熟——这些是评价，不是描述，而且暗含了"另一端才对"的预设。一律换成可验证的描述：不写"表达过激"，写"表述强度高，常用绝对化措辞，每千字 N 处"。同样的信息，去掉褒贬，且可被证伪。

**三、不沿方向外推。** 立场只记到材料划出的边界为止。"主张保护合法权益"不能推成"唯某一方论"——那不是观察，是顺着他的方向多走了几步。

做法是找**上界证据**：他有没有说过"但这里不适用""另一侧也有问题""我不是说要……"。有上界表述，就把边界一起记进去；没有，**只记下界**（他明确反对的），不填上界，也不许推测上界。

检验：**能不能用他自己的原话把这条立场的上限说出来？** 说不出来，说明上限是你推的，删掉。

### 材料不够时

立场密度差别极大：观点文、复盘文、书的前言后记最高；教程、清单、资讯最低。

取证前先看材料构成。如果全是教程类，提前告诉用户立场栏会很薄，请他补两三篇观点文或复盘——**这比硬挖有用**。

## 否决规则

这是最容易被跳过、也最影响效果的一栏。空着等于画像作废。

原因是：模型有一套强势的默认文风——长句、排比、"首先其次最后"、总分总、正确的废话、结尾行动号召。**正面描述压不住这套默认值，只有明确禁令能压住。**

生成方法：把已经写好的表达特征逐条翻面。

- 骨架是"先结论后论据" → 否决"不用总分总，不做铺垫式开场"
- 肌理是"短句、单句成段" → 否决"不用长复合句，不用排比堆气势"
- 立场是"简单逻辑优于复杂模型" → 否决"不引入没必要的框架和模型"

再加两条几乎通用的：

- 不写没有亲历案例支撑的抽象论断
- 不使用本人素材中从未出现过的词汇风格

### 每条否决规则必须标依据处数

否决规则是最容易藏猜测的一栏——表达特征每条都有依据和验证条件，禁令却常常一句话就写下了。**没有依据计数，单例就会被悄悄升格成全局禁令。**

### 单例推不出禁令，只能推出配对规则

一条做法只出现 1 次，写成"不许做 X"几乎必错——**1 次不代表这是禁区，只代表你没见过第二次。**

实践中这类条目的真相往往是：**动作是允许的，只是有配套要求。** 把禁令改写成配对规则，才对。

- ✗ 不在正文里直接推销（依据 1 处）
- ✓ 正文可以直接推销，但**必须跟一句自我限定把调门压回去**，缺这句才是错的

同理，看似"不许用某种写法"的，常常是"用法有分工"：

- ✗ 不写匿名化案例
- ✓ 要夸的人实名，可能带负面评价的匿名；**两种情况下事件的动作、对话、时间、数字都要写足**

**判断方法**：写下一条禁令前，问一句"他有没有可能在某种条件下做这件事？"想得出条件，就该写成配对规则而不是禁令。

只有依据 3 处以上、且没有反例的，才写成无条件禁令。

## 表达特征分层

四层不是按"重要程度"排的感觉分类，是按**粒度**和**替换后果**分的。分错层的代价很实际：下游在篇幅紧张时会先砍低优先级的东西，一条放错位的骨架会被当成装饰丢掉。

| 层 | 是什么 | 粒度 |
|---|---|---|
| 章法 | 全篇怎么排 | 一篇一个 |
| 骨架 | 论证怎么推进 | 一篇多次 |
| 肌理 | 节奏与句式 | 段落级 |
| 皮肤 | 用词 | 词级 |

**主判据：替换测试。** 把这条特征换成另一种做法，看坏掉的是什么。

- 换了以后论证还成立，只是不像他 → 肌理或皮肤
- 换了以后论证链断了、说服力没了 → 骨架
- 换了以后整篇读起来散了、找不到主线 → 章法

例：「凡出现数值必给推导链」——去掉推导直接给结论数字，论证断了，因为说服力全靠当场算给你看。**骨架。** 「譬如」换成「比如」——论证毫发无损。**皮肤。**

**辅判据：迁移测试。** 换题材、换篇幅，它还在吗？换题材还在且换篇幅还在 → 骨架；换题材还在但短篇里消失 → 通常是章法问题，不是骨架。

**肌理和皮肤怎么分**：能被查找替换直接改掉的是皮肤；替换需要重写整段的是肌理。

**章法层可能按文体分成几套**（观点/方法/机制类一套，叙事类一套，吐槽/冒犯类一套）。发现某篇整条章法落空时，先问是不是文体不同，再考虑是不是画像错了。

但**立一个新文体式，要求同文体 ≥3 篇且彼此一致**。两篇且互相矛盾，说明这不是一个文体，只是偶发——此时不要立新式，改在原有章法的"可变部分"里加一条例外。**取消一个立不住的文体，比强行凑出三篇准确。**

**章法层的特殊之处**：它是四层里唯一**本人自述可信**的一层。骨架、肌理、皮肤都是不自觉的习惯，问了也说不准；而谋篇布局是动笔前就定好的有意识选择，本人清楚自己在干什么。所以这一层**可以直接问，问完再回材料核对**，比从十篇里反推省得多。

同时要区分固定主体和可变部分。作者说"偶尔会故意调整开头"，那不是例外，是章法本身的一部分——固定的和可换的要分开记，否则下游会把偶发变体当成必须遵守的规则。

**章法层取证的硬门槛**：少于 5 篇同类型 A 类材料，提不出可靠章法——看不出是习惯还是巧合。此时这一层留空并进【待确认】，不要用 C 类书稿硬凑：章节排布通常由出版流程和编辑共同决定，是加工敏感度最高的东西之一。

### 每条特征必须可被证伪

一份无法判断对错的画像，坏了也不知道坏在哪，改了也不知道有没有改对。所以表达特征的每一条都要附验证条件——**拿一篇画像没用过的文章，应当据此判定命中与否。**

这还堵住一个必然发生的退化：如果验收标准是"本人觉得像"，**模糊就是稳赢策略**——具体的描述有被打脸的风险，模糊的没有。人对自己不自觉的习惯没有独立判断力，你说"他偏好短句"他会认，你编一条听起来合理的他也会认。所以不能靠本人点头验收，只能靠格式强制：写不出数量、位置、适用范围的条目，在格式上就暴露了。

**验证形式按层不同，不要套同一套格式：**

| 层 | 形式 | 例 |
|---|---|---|
| 章法 | 结构匹配，0/1 判定 | 任取一篇长文，整体结构应匹配固定主体的顺序 |
| 骨架 | 该出现的动作是否出现，计数 | 每出现一处数值必有推导链，允许 0 例外 |
| 肌理 | 密度区间 | 说理段落 ≤4 句；每篇 ≥2 处独立成段短句 |
| 皮肤 | **不验**，只列清单 | 口头禅频次随话题和心情大幅波动，精确即假精确 |

**用区间和布尔值，不用点值。** 写"≤4 句"不写"4 句"，写"≥2 处"不写"2 处"。点值必然验不过，区间才可能真，复杂度也才控得住。

**数字条件避开"行"**，行数取决于渲染宽度，手机和电脑不一样。用句数或字数。

**标注硬条件 / 软条件：**

- **硬条件**（骨架层）：违反就是错。
- **软条件**（肌理层）：统计倾向，单篇偶尔不满足属正常。

这个区分必须写进画像，因为下游若把软条件当硬条件卡，会逼出很怪的文章——模型为凑够 2 处短句，硬断两个不该断的地方。**为满足指标而写，比不满足指标更糟。**

**画像只负责给出可判定的条件，不负责执行校验。** 怎么校验、不合格怎么重写，是下游写作系统的事。画像塞进执行逻辑就不再可移植了。

另外注意：同一条规则在判定和生成两个场景下可靠性不同。**模型判断"这段是否超过 4 句"很准，但生成时不会边写边数。** 所以定性描述（"关键处单句成段"）用于生成，数量条件用于事后验收，两者都要写。

## 稳定特征与题材特征

这两者混淆会造成一个隐蔽的失败：**下游生成越来越像几年前的他。**

区分方法：

- 稳定特征 = 换个题材也不变的东西（怎么论证、什么节奏、什么立场）
- 题材特征 = 他这几年恰好在写的东西（行业、案例领域、热点）

素材有时间跨度时，看早期和近期都出现的才算稳定。只在某个时期密集出现的，归入题材范围并标注时期。
