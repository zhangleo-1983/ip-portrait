# ip-portrait · 个人内容画像抽取

一个开源的 Claude Skill：从你已有的真实内容里，抽出一份**能指导创作、并且能拿新文章验证准确度**的个人画像。


---

## 这个 skill 解决什么，不解决什么

**解决**：一次性的画像抽取。给它一批你写过的东西，它产出一份带原文依据、带否决规则、带验证条件的画像，可以直接用于约束下游生成。

**不解决**（说在前面，免得抱错期待）：

- 不解决画像的**持续更新**——新内容来了怎么迭代、怎么版本管理，不在范围内
- 不解决画像的**下游调用**——怎么接进写作流程、知识库或 agent，不在范围内
- 不做**赛道画像**——它面向单个真实的人，追求深度。批量赛道模板需要相反的抽象方向，别用它硬做
- 不做**能力评价**，也不做人格评价——不输出"你水平如何""你适合做什么""你是什么样的人"

---

## 它和市面上的"AI 人设分析"有什么不同

大多数同类产物停在这一层：

> 语言风格生动，善于举例，对读者需求有敏锐洞察

这段话换个人也成立，所以它约束不了任何生成，也没法判断它对不对。

这个 skill 的硬性要求是：

- **每条特征必须有原文依据**，先取证再归纳，顺序不能反
- **禁止万能评价**——一句话套到同行另一个人身上如果也成立，就删掉
- **每条特征必须可被证伪**——附带验证条件（数量、位置、适用范围），拿一篇没见过的文章能直接判命中或未中
- **必须产出否决规则**，因为模型的默认文风（长句、排比、总分总）靠正面描述压不住，只有明确禁令能压住
- **区分稳定特征与题材特征**，否则生成的内容会越来越像几年前的你
- **不确定就留问题**，不用"可能/或许"填空

---

## 四个层次

画像的表达特征分四层，下游生成时优先级依次递减：

| 层 | 是什么 | 粒度 |
|---|---|---|
| **章法** | 全篇怎么排 | 一篇一个 |
| **骨架** | 论证怎么推进 | 一篇多次 |
| **肌理** | 节奏与句式 | 段落级 |
| **皮肤** | 用词 | 词级 |

分层不是感觉分类，靠**替换测试**判：把这条特征换掉，坏的是论证（骨架）、是整篇结构（章法），还是只是不像他了（肌理/皮肤）。

## 怎么用

1. 把整个目录放进你的 skills 目录，或在 claude.ai 的设置里上传为自定义 skill
2. 准备至少 5 篇你自己的真实内容——公众号原文、私人笔记、逐字稿都行，越未经他人编辑越好
3. **另外扣下 1 篇不参与归纳**，留给最后一步验证
4. 直接说："帮我做一份内容画像"

它会先问你素材的来源属性（谁编辑过、口语还是书面、长还是短、有没有虚构），这一步不能跳——属性标错，后面所有归纳的权重都是错的。

---

## 怎么判断它做对了

**不要读完画像判断"像不像"。** 那个答案没有判别力：真的你会认，编得合理的你也会认。人对自己不自觉的习惯没有独立判断力。

正确的做法是跑**留一验证**：交出那篇没参与归纳的文章，逐条判定命中率。

- 命中率低于七成 → 画像有实质问题，回去重新归纳
- 判定只有三档：命中 / 未中 / N/A，**不给半分**

实测下来，验证暴露的往往不是"画像错了"，而是"少归纳了一类"——比如某篇整条章法落空，通常是文体不同，不是画像坏了。

```
    ├── materials.md          素材的四个属性、材料类型速查、加工痕迹判定

```

## 已知边界

诚实说明，免得你踩同样的坑：

- **只在中文书面长文上验证过。** 短内容（<800 字）、口语转写、其他语种、虚构类作品都没验过
- **口语材料需要独立的肌理层和章法层。** 转写稿的分段是转写工具决定的，不是作者决定的，书面的节奏指标量不了口语
- **它是从一个人的素材上磨出来的。** 每条规则背后都有一次实测，但有些结论可能是那个人的特征而非普遍规律

## 反馈

用完之后，无论好用还是踩坑，欢迎开 issue。**最有价值的是"它在我身上没跑通"那类**，具体说：

- 它在你的素材上产出了万能评价（取证环节没兜住）
- 否决规则那一栏填不满（你的素材类型我没覆盖到）
- 留一验证命中率很低，但你觉得画像其实是对的（说明验证条件设计有问题）

这些会直接进下一版。
